# Blue Wings of the Pacific (태평양의 푸른날개)

항공모함에서 날아올라 섬을 하나씩 되찾는 2D 비행 게임입니다. 폰(가로 화면)과 컴퓨터에서 바로 할 수 있어요.

**바로 하기:** https://seungbeom-code.github.io/hellcat-carrier/

- 한 번 열어 두면 인터넷이 없어도 열립니다. 폰에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치할 수 있어요.
- 조종: ▲▼ 기수, 가는 방향 키 = 가속, 반대 방향 키 = 선회. Space 기관총, C 로켓·폭탄·어뢰(격납고에서 고른 무기). 화면 버튼으로도 됩니다.
- 갑판에서 ◀▶ 를 누르고 있으면 가속해 이륙하고, 엘리베이터 위에서 Space 를 누르면 급유·수리·무장 선택을 합니다.
- 임무를 마치면 항모로 돌아와 착함하고 엘리베이터로 내려가야 작전이 끝납니다.
- 작전은 레벨마다 새로 만들어지고, 레벨이 오를수록 섬·함정·적기가 늘어납니다.
- 게임 안 "How to play (H)"에 자세한 규칙이 있습니다.

파일 하나(`index.html`)로 된 게임입니다. 그림과 소리는 모두 코드로 만듭니다.
